# OOPS in Java College Programs

This repository contains Object-Oriented Programming System (OOPS) Java lab programs organized by experiment folders. It is useful for college students preparing practical files, viva questions, and Java programming practice.

## Why this repository

- Clean collection of Java OOP experiment programs
- Beginner-friendly examples for classes, objects, arrays, strings, sorting, and simple systems
- Structured folder layout for fast browsing and assignment submission

## How to run Java files

1. Open a terminal in the project root.
2. Compile a file:

```bash
javac expt1/Palindrome.java
```

3. Run the compiled class:

```bash
java -cp expt1 Palindrome
```

For files in other folders, replace the path and class name accordingly.
